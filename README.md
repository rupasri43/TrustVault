# TrustVault

### Secure Document Sharing with a Real Audit Trail

TrustVault is a security-focused document-sharing platform
designed to protect confidential documents through
document-level permissions and verifiable audit records.

## User Roles
- Administrator
- Document Owner
- Viewer

## Technology Stack
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Core Features
- Secure authentication
- Document upload and management
- Document-level access control
- Permission granting and revocation
- Secure document downloads
- Audit trail
- Security testing
